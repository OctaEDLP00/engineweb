Un cargador de assets resiliente y caché de memoria GPU (texturas, modelos 3D, audio, sprite sheets) con límites de concurrencia, reintentos con backoff exponencial y purga LRU.

El diseño refleja los patrones de recursos de [Effect](https://effect.website/) — concurrencia acotada como un semáforo, reintentos planificados con backoff y ámbitos abortables vía `AbortSignal` — y encaja en pipelines de descarga con `Stream`/`Effect`.

## Uso

<Steps>

1. Crea el pipeline con tus presupuestos de concurrencia, reintentos y memoria:

   ```typescript
   import { AssetPipeline } from '@engineweb/effect-asset-pipeline'

   const assets = new AssetPipeline({
     concurrency: 6,
     maxRetries: 3,
     cacheBudgetBytes: 256 * 1024 * 1024,
   })
   ```

2. Carga un nivel con timeout global — las URLs duplicadas comparten un solo fetch:

   ```typescript
   const controller = new AbortController()
   setTimeout(() => controller.abort(), 30_000)

   const [diffuse, level, theme] = await Promise.all([
     assets.load({ url: '/texture/arena.ktx2', kind: 'texture', signal: controller.signal }),
     assets.load({ url: '/models/arena.glb', kind: 'model', signal: controller.signal }),
     assets.load({ url: '/audio/theme.ogg', kind: 'audio', signal: controller.signal }),
   ])
   ```

3. Sube a la GPU y purga hasta el presupuesto al cambiar de nivel:

   ```typescript
   uploadToGpu(diffuse) // ArrayBuffer, cached — the next load() for this URL is free
   assets.purge()
   ```

</Steps>

Dentro de Effect:

```typescript
import { Effect } from 'effect'
import { AssetPipeline } from '@engineweb/effect-asset-pipeline'

const loadAsset = (url: string) =>
  Effect.tryPromise({
    try: () => assets.load({ url, kind: 'texture' }),
    catch: (cause) => new AssetError({ url, cause }),
  }).pipe(Effect.withSpan('asset.load'))
```

## Referencia de la API

### `new AssetPipeline(options?)`

| Opción             | Defecto   | Descripción                                              |
| ------------------ | --------- | -------------------------------------------------------- |
| `concurrency`      | `6`       | Máximo de fetches simultáneos. Entero positivo.          |
| `maxRetries`       | `3`       | Reintentos tras el primer intento. Entero no negativo.   |
| `cacheBudgetBytes` | `256 MiB` | Presupuesto blando en bytes. No negativo.                |

Todas las opciones validan con `RangeError` ante valores malos.

### Métodos

| Método                                             | Descripción                                                                                                       |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `load(request)`                                    | Descarga (o trae de caché) un asset. Las cargas duplicadas concurrentes comparten un fetch. `TypeError` sin URL.  |
| `purge()`                                          | Expulsa lo menos usado hasta volver al presupuesto.                                                               |
| `clear()`                                          | Vacía la caché sin condiciones.                                                                                   |
| `get cachedByteCount()` / `get cachedEntryCount()` | Telemetría de la caché.                                                                                           |

**`AssetRequest`**

| Campo       | Descripción                                                                                                      |
| ----------- | ---------------------------------------------------------------------------------------------------------------- |
| `url`       | `string` o `URL`. La clave de caché es `String(url)`.                                                            |
| `kind`      | `'texture'` \| `'model'` \| `'audio'` \| `'sprite-sheet'` \| `'binary'`. Informativo; reservado para presupuestos. |
| `priority?` | Reservado para planificación por prioridad. Aceptado, hoy solo consultivo.                                       |
| `signal?`   | `AbortSignal` que cancela espera en cola, fetch y sleeps de reintento.                                           |

<Aside type="caution">
  Los buffers en caché se comparten, no se copian — trátalos como solo lectura tras resolver `load()`.
</Aside>
